# Local MQTT Test Server

This folder contains a small MQTT test broker (using `amqtt`) you can run locally for development and testing.

Files:
- `Server.py` - small wrapper that writes test credentials and starts the broker using `broker_config.yaml`.
- `broker_config.yaml` - broker configuration. Binds to `127.0.0.1:9001` by default.
- `passwords.txt` - generated by `Server.py` on start (contains hashed passwords).
- `requirements.txt` - Python requirements for the test server.
- `run_test_server.ps1` - PowerShell helper to create a venv, install deps and run the server.

Default credentials (for quick tests):
- user: `test_user`
- password: `test_password`

How to run (PowerShell):

```powershell
cd .\regiokargotramtrain_app\MQTT_Test_Server
.\run_test_server.ps1
```

Then run your Flutter app (it is configured by default to connect to `localhost:9001`).

If you need the broker to be reachable from other hosts (e.g. Pi on network), change `broker_config.yaml` `bind` to `0.0.0.0:9001` and ensure firewall allows access.
